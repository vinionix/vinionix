## O que estou construindo agora

### [From Zero to MiniGPT](https://github.com/vinionix/from-zero-to-minigpt)

Projeto de longo prazo para entender e implementar IA desde os fundamentos matemáticos até um pequeno Transformer decoder-only.

O foco não é apenas usar frameworks: a proposta é estudar a matemática, implementar, testar, experimentar e documentar cada etapa até chegar a um MiniGPT e, depois, a um sistema completo com RAG, ferramentas, avaliações e segurança.

### [CPU LLM Lab](https://github.com/vinionix/teste_ia)

Laboratório CPU-only para comparar pequenos LLMs locais em uma tarefa de consulta fundamentada em documentos.

O benchmark observa fidelidade factual, recuperação de fontes, recusa quando não existe evidência, latência, tokens e throughput para estudar o trade-off entre **qualidade e custo computacional**.

### [AgentOps Triage](https://github.com/vinionix/agentops-triage)

MVP de triagem técnica com workflow multi-step para classificação, prioridade, diagnóstico e resposta estruturada.

O projeto conecta minha experiência anterior em suporte/redes com a direção atual em IA e explora FastAPI, Pydantic, LangGraph, LangChain e arquitetura preparada para integração incremental com LLMs.
